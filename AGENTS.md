# AGENTS.md

Sudhaa Jol is a water delivery app: customers place orders and track them by code; staff manage all orders in an admin panel.

## Architecture

| Layer     | Technology                                                    |
| --------- | ------------------------------------------------------------- |
| Framework | TanStack Start (React 19, TanStack Router, file-based routes) |
| Styling   | Tailwind CSS 4, theme variables in `src/styles.css`, shadcn/ui |
| Data      | Netlify Database (Postgres) via Drizzle ORM (`drizzle-orm@beta`) |
| Files     | Netlify Blobs store `product-images` (product photos)          |
| Auth      | Netlify Identity (`@netlify/identity`), admin = `admin` role  |
| Hosting   | Netlify via `@netlify/vite-plugin-tanstack-start`              |

All server logic is in TanStack server functions (`src/lib/orders.functions.ts`, `src/lib/products.functions.ts`), called from route loaders and components. The only server route is `src/routes/product-images/$key.ts`, which streams photos from Blobs.

## Non-obvious decisions

- **Products live in the `products` table** and are managed from the admin Products tab. The original four were seeded by a migration; `jar-20l` is used by the admin "jars to deliver" stat and the default basket. Hidden (`active = false`) products are not orderable.
- **Product photos** are resized in the browser (max 1200px WebP), stored in Blobs under a fresh key per upload, and shown via `/.netlify/images?url=/product-images/<key>` (`productImageUrl`).
- **Prices are server-authoritative.** The client sends only product IDs and quantities; `placeOrder` looks up active products in the database and stores a snapshot (`items` jsonb with name + unit price) so later price changes don't rewrite history.
- **Every status change writes an `order_events` row.** The customer timeline and admin history are built from it. The latest status is also denormalised onto `orders.status`.
- **Order codes** are `SJ-` + 6 random characters from an unambiguous alphabet. The code is the customer's only credential for tracking, so the tracking response masks the phone number and shows only the first name.
- **Admin authorization is enforced in the `requireAdmin` middleware** on every admin server function, not just the page. Roles come from Identity `app_metadata` and are set in the Netlify dashboard.
- **Times are formatted in `Asia/Kolkata`** (see `catalog.ts`) so SSR and browser output match and avoid hydration mismatches.
- Currency is INR (`formatPrice`).

## Conventions

- Import from `src` with `@/`; db imports use relative paths with `.js` extensions.
- Use theme variable classes (`bg-primary`, `text-muted-foreground`), not raw colors. Fonts: Fraunces (`font-display`) for headings, Plus Jakarta Sans for body.
- Validate all server-function input with `.validator(zod)`.
- Schema changes: edit `db/schema.ts`, then `npx drizzle-kit generate --name <imperative_snake_case>`. Never apply migrations manually.
- Read `localStorage` and the current date only inside effects.
- Strict TypeScript: no unused locals/params.
